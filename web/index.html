Kanban 시작하기

  1. 평소처럼 Codex나 Claude Code를 사용하세요.

    터미널이나 로컬 세션 로그를 남기는 IDE·Orca에서 작업을 시작하세요. Kanban 전용 실행 명령은 필요하지 않습니다.

  2. 프로젝트와 카드가 자동으로 생깁니다.

    최근 7일 안에 갱신된 로컬 세션을 읽고, 작업 폴더별 프로젝트에 세션당 카드 하나를 등록합니다.

  3. 대화를 이어가면 같은 카드가 갱신됩니다.

    최신 요청·응답·사용량을 확인하고, 카드 상세의 대화 이력에서 이전 질문과 답변도 펼쳐보세요. 완료는 최신 응답이 끝났다는 뜻이며, 새 요청이 오면 진행 중으로 돌아갑니다.

  4. 수집 상태를 직접 확인하세요.

    대시보드 서버가 실행 중일 때 약 5초마다 확인합니다. ‘지금 확인’으로 다시 확인하거나 ‘일시정지’로 수집을 멈출 수 있습니다.

원본 로그와 도구 설정은 변경하지 않습니다. 로컬 로그가 없는 원격·클라우드 세션은 수집되지 않습니다. 완료 기록 없이 15분 동안 새 기록이 없으면 ‘상태 확인’으로 표시합니다. 왼쪽 메뉴의 Obsidian ‘연동 설정’에서 프로젝트마다 Obsidian 자동 저장 또는 선택 저장을 켤 수 있습니다.

저장 방식
  • 자동 저장 — 이 프로젝트의 모든 프롬프트를 자동으로 노트에 저장합니다.
  • 선택 저장 — 카드의 프롬프트에서 ☆ Obsidian에 저장을 누른 것만 저장합니다. 그 프롬프트가 실행한 하위 세션도 함께 저장됩니다.
  • Vault 안의 Kanban/프로젝트/ 폴더에만 세션당 노트 하나를 만듭니다. 편집한 노트는 덮어쓰지 않고, 연동을 끄거나 선택을 해제해도 노트를 지우지 않습니다.
